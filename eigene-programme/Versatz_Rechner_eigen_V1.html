Rechenweg

  1. ΔX = (W2 − W3) / 4. Zunge 2 und 3 haben je eine Flanke aus B180. Liegt die Drehachse um a neben dem Nullpunkt, verschiebt sich alles aus B180 um 2a → eine Zunge wird um 2a schmaler, die andere um 2a breiter. Probe: (W2 + W3)/2 = (W1 + W4)/2. Werkzeugradius und Abdrängung fallen heraus. Vorzeichen: G54/G55-X neu = alt + ΔX.
  2. Längenoffset = (Mittel T − 6,000) / 2. Das Werkzeug fährt beide Seiten an, ein Längenfehler geht doppelt in die Dicke. Herkunft im Messzyklus measureTool.nc: ToolLength = MESS.Z − ToolOffset. Plättchen zu dünn → Werkzeug real länger als gespeichert → Offset kleiner (negative Korrektur addieren). Gleiche Konvention wie der HEDS-Rechner.
  3. ΔA = atan((T1 − T4) / (4 · Abstand)). Eine A-Kippung macht das Plättchen keilförmig, von beiden Seiten gleichsinnig. Vorzeichen wie HEDS: Y+-Seite (Loch) dicker → positiv. A neu = A alt + ΔA, bei G54 und G55 gleich. ❓ Vorzeichen noch nicht am eigenen Teil bestätigt.
  4. Folgewerte: G59-Z neu = alt + Längenoffset-Korrektur (die Planfläche bei A −90 entsteht mit der Werkzeugspitze). Rund-Ø der A0-Tonne erwartet = bisher − 2 · Korrektur. Bleibt ein Rest zu 10,000, ist das G58-Z: neu = alt + (5,000 − D/2).

Rechenweg und Grenzen

  1. G59-Z neu = alt + (19,500 − L nach). Planfläche zu tief (Teil kurz) → Z nach +.
  2. G58-Y neu = alt + (Soll − Ist) mit Soll = Länge − 15,000. Schulter zu nah an der Stirn → Y nach +. Messschieber: unter 0,02 Abweichung nicht korrigieren, lieber zwei Läufe mitteln.
  3. G58-X neu = alt + (M1 − M2)/2; Kontrolle (M1 + M2)/2 − D/2 − 4,750 ≈ 0. G58-Z: Abweichung = 5,000 − D/2. Darin steckt der Werkzeug-Längenoffset 1:1 – erst Plättchen, dann der Rest in G58-Z.
  4. G59-X neu = alt + (M1 − M2)/2; G59-Y neu = alt + M3 − (M1 + M2)/2; Kontrolle (M1 + M2)/2 − D/2 − 5,000 ≈ 0.
  5. Der Werkzeug-Längenoffset wirkt nur auf Maße, die mit der Werkzeugspitze entstehen: Rund-Ø bei A0 (G58-Z), Planfläche bei A −90 (G59-Z), Plättchendicke. Flanken-Maße (G58-X, G58-Y, G59-X, G59-Y) bleiben unverändert.
